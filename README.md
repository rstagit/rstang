# RSTA NG - فورک پیشرفته V2RayNG با اتصال هوشمند و دور زدن فیلترینگ

**RSTA NG** یک نسخه اصلاح‌شده و توسعه‌یافته (Fork) از کلاینت محبوب [V2RayNG](https://github.com/2dust/v2rayNG) است. این برنامه با هدف پایدارسازی اتصال، مدیریت هوشمند ترافیک و استفاده از تکنیک‌های پیشرفته برای عبور از سد فیلترینگ و سانسور شدید اینترنت طراحی شده است.

## ✨ ویژگی‌های کلیدی

- ⚡ **اسکنر داخلی آی‌پی تمیز کلودفلر (Cloudflare Clean IP Scanner):** قابلیت یافتن و جایگزینی خودکار آی‌پی‌های تمیز و بدون فیلتر کلودفلر برای افزایش چشمگیر سرعت و پایداری اتصال.
- 🔄 **اتصال مجدد خودکار (Auto-Reconnect):** پایش مداوم وضعیت شبکه و برقراری اتصال خودکار و آنی پس از قطعی اینترنت یا تغییر شبکه (Wi-Fi / Mobile Data).
- 🛡️ **تکنیک‌های پیشرفته اسپوفینگ (Traffic Spoofing):** دستکاری و تغییر الگوهای ترافیک جهت فریب سیستم‌های فیلترینگ هوشمند و بازرسی عمیق بسته‌ها (DPI).
- 🚀 **بهینه‌سازی شده برای فیلترینگ شدید:** بازنویسی برخی مکانیزم‌ها جهت عملکرد پایدار در شرایط اختلال شدید اینترنت.
- 🔋 **سبک و بهینه:** توسعه‌یافته بر پایه آخرین نسخه هسته V2Ray با کمترین میزان مصرف باتری و منابع سیستم.

## 🛠️ آموزش ساخت و کامپایل از سورس (Build)

اگر تمایل دارید پروژه را خودتان کامپایل کنید، دستورات زیر را در ترمینال اجرا کنید:

```bash
